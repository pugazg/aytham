# Experiment 003B — Sangam Context Inference Case Study v0.1

## Objective

Test whether the Aytham semantic model can represent meaning where information is not fully explicit.

Unlike the banking case study, this experiment focuses on:

- observation
- context
- inference
- uncertainty
- evidence

## Research question

Can a programming model preserve the difference between:

- what is observed
- what is inferred
- what is uncertain
- what is established?

## Literary analogy boundary

Sangam literature is not being converted into programming concepts.

The purpose is to study a semantic problem:

> How can meaning be reconstructed from incomplete explicit information?

## Semantic flow

```
Observation
    ↓
Possible interpretations
    ↓
Evidence evaluation
    ↓
Resolved claim
```

## Example model

Observation:

```
Mountain imagery appears in text
```

Possible claims:

```
Claim A:
    literal mountain reference

Claim B:
    symbolic landscape/context reference
```

Evidence sources:

```
- surrounding text
- grammatical constraints
- commentary
- corpus metadata
```

Final state:

```
Claim {
    value
    evidence
    confidence
    authority
}
```

## Aytham relevance

This experiment tests whether Aytham can model:

```
Known
Derived
Inferred
Unknown
Disputed
```

as distinct semantic states.

## Initial conclusion

The promising area is not literary processing itself. The promising area is a general programming model where interpretation and evidence are explicit rather than hidden inside application logic.
